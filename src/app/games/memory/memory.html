Memory Game

Instrucciones

El juego consiste en un tablero de cartas boca abajo. El objetivo es encontrar pares de cartas iguales. Los jugadores se turnan para voltear dos cartas a la vez. Si las cartas coinciden, el jugador las retira del tablero y puede continuar jugando. Si no coinciden, las cartas se vuelven a colocar boca abajo y el turno pasa al siguiente jugador. El juego continúa hasta que se hayan encontrado todos los pares de cartas.
